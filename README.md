# 网页视频遥控器 · WebVideoRemote

玩游戏时**不用切窗口、不用 Alt+Tab**，直接用手边的键控制浏览器里正在放的 B站 / 抖音。

- `CapsLock` —— 播放 / 暂停
- `←` `→` —— 快退 / 快进
- `↑` `↓` —— 抖音：上一个 / 下一个视频
- 按住 `→` —— 抖音：**按下就开始快进**，按满长按阈值后松手 = 设为 1 倍速（轻点 = 恢复原速）

程序常驻托盘，全程后台运行，不占用游戏操作（可按需选择是否"吞掉"这些键）。

---

## 一、直接使用

1. 双击 `dist\网页视频遥控器.exe`（不需要安装，不需要 Python/Node）。
2. **装一次浏览器桥接扩展**（只有抖音的 `↑`/`↓`、长按快进需要它，2 步搞定）：
   - 在程序窗口点「装桥接扩展」按钮，它会告诉你步骤并打开 `dist\extension` 文件夹；
   - 浏览器地址栏输入 `edge://extensions`（Chrome 用 `chrome://extensions`）→ 打开「开发人员模式」→「加载解压缩的扩展」→ 选中那个 `extension` 文件夹。
   - 详细图文说明见 `dist\extension\安装说明.txt`。
3. 在 Edge / Chrome 里打开 B站 或 抖音，并且**正在播放**。
4. 程序窗口会显示当前控制的是哪个视频、桥接脚本是否已连接；然后就能用上面的热键了。
5. 点窗口右上角 × 会缩到托盘继续工作；要彻底退出用「退出程序」按钮或托盘右键菜单。

> 系统要求：Windows 10 / 11（自带 .NET Framework 4.8 即可，无需额外安装运行时）。
>
> **本程序以管理员权限运行**（双击会弹一次 UAC 确认）。这是必须的：原神等游戏的进程是管理员权限，
> 而 Windows 的 UIPI 机制会阻止普通权限程序收到发往管理员窗口的按键 —— 那样在游戏里热键会完全没反应。
> 勾选「开机自动启动」时会自动改用任务计划（最高权限），所以登录时不会再弹 UAC。

### 首次使用建议
程序窗口 →「自检并写日志」，它会告诉你：键盘钩子是否装上、有没有检测到播放会话、找没找到浏览器窗口、桥接脚本连没连上。
之后按一下 `CapsLock`，看窗口标题栏有没有出现「播放/暂停」的动作提示。

## 二、能力说明（这一节很重要）

后台控制网页播放器有几条完全不同的物理通道，程序会按顺序尝试，并在界面上告诉你**这次用的是哪一条**：

| 通道 | 原理 | 实测结论 |
|---|---|---|
| ① 浏览器脚本桥接 | exe 起一个只监听本机 127.0.0.1:17777 的小服务，浏览器里的小扩展长轮询取指令，直接操作网页里的播放器 | ✅ **本机用真实 Edge 验证通过**：指令即时送达、页面按键事件正常、播放/暂停与长按变速（1x↔2x）都生效；**完全不碰焦点、不依赖按键注入** |
| ② 系统媒体控制（SMTC） | 走 Windows 系统级媒体接口，浏览器主动上报的"媒体会话" | ✅ **本机用真实 B站 / 抖音 页面实测全部有效**，暂停/播放、精确跳转（±30s 一次到位）；同样不碰焦点 |
| ③ 抢焦点按键注入 | 把浏览器窗口临时置前 → 注入真实扫描码按键 → 立刻把焦点还给游戏 | ⚠️ 兜底用。**实测在部分环境会失效**（远程桌面/虚拟桌面、以及 Chromium 拒绝跨进程键盘消息的场景），失败时程序会明确记录「抢焦点失败」并且不乱发按键 |
| ④ 后台投递按键（实验） | 直接把键盘消息投给浏览器窗口，不改焦点 | ❌ **Chromium 会拒绝**（返回"拒绝访问"，顶级窗口和渲染子窗口都拒），默认关闭 |

具体到两个网站：

| 功能 | B站 | 抖音 |
|---|---|---|
| `CapsLock` 播放/暂停 | ✅ 系统媒体控制，后台无感 | ✅ 走桥接扩展（没装扩展时退回系统媒体控制） |
| `←` `→` 快退/快进 | ✅ 系统媒体控制，精确跳转 | ✅ 系统媒体控制 |
| `↑` `↓` 切换视频 | — | ✅ 走桥接扩展（装上扩展后完全不抢焦点） |
| 长按 `→` 持续快进 | — | ✅ 走桥接扩展（直接把网页视频调成 2 倍速，长按后松手设为 1 倍速） |

补充说明：

- **抖音为什么优先走桥接**：抖音网页对 Windows「系统媒体控制」的播放/暂停经常"返回成功但不真动作"，`↑`/`↓` 更是完全不认，所以抖音模式下这几项都交给网页脚本直接操作播放器（本机实测双向可靠）。
- **装了桥接扩展之后，抖音的这些功能都不再抢焦点**；如果没装扩展，程序会退回"抢焦点按键注入"，而这条通道在部分机器上是无效的。
- 每次热键动作都会写进日志，脚本执行完还会回一条「脚本回执」，所以出问题时打开日志就能看出卡在哪一步。
- **一个浏览器同时只上报一个播放会话**。同时开多个 B站/抖音 标签页时，程序控制的是浏览器当前"活跃"的那一个。
- 没装扩展、又关掉「抢焦点按键注入」时，抖音的 `↑↓` 和长按快进就不生效，其余功能照常。
- **游戏里完全没反应（原神等）**：这些游戏的进程是管理员权限，本程序也必须以管理员身份运行。
  现在程序默认就会请求管理员权限（弹一次 UAC 点「是」即可）；日志里会写「权限: 管理员」。

## 三、界面选项

| 选项 | 说明 |
|---|---|
| 网站模式 | `B站` / `抖音` / `自动识别`（按当前播放的网站标题自动切换，推荐） |
| 启用热键 | 总开关，临时不用可关 |
| 拦截 CapsLock | 吞掉 CapsLock：不会切换大小写、键盘指示灯也不亮 |
| 拦截 ← → | 默认**不**拦截（游戏里还能用方向键）。勾上后这两个键不再传给游戏 |
| 拦截 ↑ ↓ | 同上，抖音模式下用 |
| 浏览器脚本桥接 | 抖音 `↑↓`、长按快进 首选通道，需先装 `extension` 扩展 |
| 系统媒体控制 | B站首选通道，建议保持开启 |
| 抢焦点按键注入 | 兜底通道（没装扩展时抖音 `↑↓` 会用它） |
| 后台投递按键 | 实验项，Chromium 会拒绝，建议保持关闭 |
| B站步长 / 抖音跳转 | 一次快进快退多少秒 |
| 长按阈值 | 按住 `→` 超过多少毫秒算"长按"（默认 350ms）：按住期间一直快进；按满这个时长松手会设为 1 倍速，短于它松手则恢复原来的倍速 |
| 开机自动启动 | 以管理员权限注册「任务计划」，登录时静默启动、不弹 UAC |
| 关闭窗口时缩到托盘 | 默认开启 |

配置保存在 exe 同目录的 `WebVideoRemote.ini`，日志在 `WebVideoRemote.log`。
状态栏第二行会显示「脚本已连接 / 脚本未连接」——没连上就说明扩展没装好或页面没刷新。

## 四、命令行诊断

程序也能当诊断工具用（`--cli` 后面的输出同时写入 exe 同目录的 `WebVideoRemote-cli.txt`）：

```
网页视频遥控器.exe --cli status        列出系统媒体会话 + 检测到的浏览器窗口 + 当前配置
网页视频遥控器.exe --cli toggle        直接触发一次播放/暂停
网页视频遥控器.exe --cli seek 30       相对跳转 +30 秒（负数即快退）
网页视频遥控器.exe --cli next          下一个
网页视频遥控器.exe --cli mode 1        切换为抖音模式（0=B站 1=抖音 2=自动）
网页视频遥控器.exe --cli focus 28 1    测试"抢焦点注入 ↓"到抖音窗口（0x27=→ 0x28=↓）
网页视频遥控器.exe --cli bridge next   启动桥接服务、等扩展连上，然后发一条指令给网页
网页视频遥控器.exe --cli hooktest      安装键盘钩子 4 秒并自注入按键，验证钩子是否工作
网页视频遥控器.exe --cli help          全部命令
```

## 五、常见问题

**按了没反应？**
1. 先看程序窗口底部状态：是不是「未检测到浏览器播放会话」——浏览器里得有正在播放的视频（暂停状态也可以，但要有会话）。
2. 点「自检并写日志」看钩子是否安装成功、有没有找到浏览器窗口。
3. 游戏是管理员权限 → 本程序也要用管理员权限运行。
4. 杀毒软件/安全软件拦截全局键盘钩子 → 加白名单。

**B站能控、抖音 `↑↓` 不动？**
先确认扩展装好并且状态栏第二行显示「脚本已连接」；没连上就刷新一下抖音页面。
连上了还不切视频，说明抖音的页面结构变了：用
`网页视频遥控器.exe --cli bridge next` 试一次，把日志（`WebVideoRemote.log`）发我，我按新结构改选择器。
（桥接脚本里内置了三种换视频方式：模拟 ↑/↓ 键、滚动信息流、点页面自带的切换按钮，会自动依次尝试。）

**为什么按 `←` `→` 游戏里角色也在动？**
因为默认不拦截方向键。勾上「拦截 ← →」，这两个键就只给遥控器用。

**会不会被我游戏的反作弊误判？**
程序只做两件事：安装标准 Windows 键盘钩子、调用系统媒体控制接口，
不做注入进程/改内存等操作。但个别严格的反作弊仍可能对全局钩子敏感，请自行斟酌。

## 六、从源码重新构建

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

- `src/` 是全部源码（C#，.NET Framework 4.8 + WinForms，无第三方依赖）。
- 产物：`build\WebVideoRemote.exe`，脚本会同时复制到 `dist\网页视频遥控器.exe`。
- `tools/` 是开发时用的本地测试台（`harness.js` 起一个带 `<video>`/`<audio>` 的本地页面，
  用 Edge 打开后可通过 `cdp.js` 观察页面到底收没收到按键），跟正式程序无关。

需要 Visual Studio 的 C# 编译能力，或者 .NET SDK（`dotnet build`）。
